# Mistakes

Append-only. Every quiz miss, wrong complexity guess, and bug that cost time goes here.
Format: `- YYYY-MM-DD | <problem id> | <what went wrong>`

Not a shame list — a targeting list. At 10, 20, 35, 50, 65 and 75 solved we read this back,
find the recurring category (boundary conditions? complexity misjudgment? coding before
thinking?), and change the routine to attack it.
