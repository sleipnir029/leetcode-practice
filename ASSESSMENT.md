# Assessments

Milestone reads on how the thinking is evolving — the qualitative layer the dashboard can't
compute. Written at 10 / 20 / 35 / 50 / 65 / 75 solved (or on `/assess`). Newest at the top.

Each entry judges the *reasoning*, not the counts: are pre-code plans getting crisper, are
complexity guesses landing, is optimal-first improving, which mistakes recur, which patterns are
truly internalized. Reading an old entry against a new one is where the signal is.
